# Writeup

The bot only knows seven PlacidWay pages, and those pages are incomplete in ways an answer cannot invent. The comparison table stops at the first Load More batch, so later clinics are absent and a Turkey-or-Mexico comparison is only as complete as that first screen. No package page states a recovery time. They state a 3-week program and a follow-up after 3 months, which is not recovery, so those questions have to say the duration is not listed. The video page is titles only, with no transcripts, so nothing can be said about what a video actually says. Comparison prices are the centers' estimates, not ITC package quotes, and the reply has to keep that distinction. The knowledge base is small: three cancer packages, one clinic profile, a price list, a video page, and one comparison page. The price list also has a dirty row with a blank procedure name and a price of $18,995. That row is stored and kept out of answers rather than assigned to a cancer.

With another week I would page through Load More until the comparison table stopped growing, and store each clinic with its city. I would separate program length from recovery in the index. I would transcribe the videos, or drop that page from retrieval until transcripts exist. I would drop the blank price-list row at extract time and flag the colorectal cell that repeats the price as text. I would refresh the index when a page hash changes, and I would run the eval set on every change so a prompt edit cannot silently drop a required answer.
